# Module 1 — Network Baseline

## Host
- Platform: Apple MacBook Pro
- CPU: Apple M3
- Architecture: arm64
- Operating System: macOS 15.6.1
- Active interface: en0 (Wi-Fi)

## IPv4 Configuration
- IP address: 10.7.29.220
- Subnet mask: 255.255.224.0
- CIDR: 10.7.0.0/19
- Broadcast: 10.7.31.255
- Default gateway: 10.7.0.1
- MTU: 1500

## Connectivity
The default gateway was reachable with 0% packet loss.

The host LAN address was also reachable with 0% packet loss.

ICMP tests to public addresses were not used as proof of Internet connectivity because the network may filter ICMP. HTTPS and DNS connectivity were tested separately.

## Purpose
This baseline establishes the Layer 2/Layer 3 environment in which the private DNS service is deployed.
